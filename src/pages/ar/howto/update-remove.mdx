## الأوامر حسب طريقة التثبيت

اختر التبويب المطابق للأمر الذي كتبته حينها:

- `npx skills add` ← سطر أوامر skills
- `/plugin install` ← إضافة Claude Code
- `/add-plugin` ← إضافة Cursor

لا تتذكّر؟ إذا كانت الأوامر تحتاج إلى البادئة `pstack:`، فأنت تستخدم إضافة Claude Code.

<Tabs id="ur" items={[["skills","سطر أوامر skills"],["cc","إضافة Claude Code"],["cursor","إضافة Cursor"]]}>
<div slot="skills">
<p>شغّل هذه الأوامر في الطرفية (وليس في مربع المحادثة مع الذكاء الاصطناعي):</p>
<p><Cmd c="npx skills list" /> اعرض المهارات المثبّتة.</p>
<p><Cmd c="npx skills check" /> تحقّق من وجود إصدارات جديدة.</p>
<p><Cmd c="npx skills update" /> حدّث إلى أحدث إصدار.</p>
<p><Cmd c="npx skills remove" /> ألغِ تثبيت المهارات.</p>
<p>المهارات المثبّتة من دون <code>-g</code> توجد فقط في المشروع الذي كنت فيه حينها.</p>
</div>
<div slot="cc">
<p>لا تتحدّث الإضافات الخارجية تلقائيًا في الوضع الافتراضي. للتحديث يدويًا مرة واحدة (شغّل الأمر في الطرفية):</p>
<p><Cmd c="claude plugin update pstack@cursor-plugins" /></p>
<p>للتحديث تلقائيًا: اكتب <code>/plugin</code>، وافتح تبويب <strong>marketplaces</strong>، وحدّد <code>cursor-plugins</code>، ثم اختر <strong>enable auto-update</strong>.</p>
<p>اكتب هذه الأوامر في مربع محادثة Claude Code:</p>
<p><Cmd c="/plugin list" /> اعرض الإضافات المثبّتة وتحقّق مما إذا كانت مفعّلة.</p>
<p><Cmd c="/plugin uninstall pstack@cursor-plugins" /> ألغِ التثبيت.</p>
<p><Cmd c="/plugin disable pstack@cursor-plugins" /> أوقفها مؤقتًا. يمكنك إعادة تفعيلها لاحقًا بالأمر <code>/plugin enable pstack@cursor-plugins</code>.</p>
<p>بعد إلغاء التثبيت أو الإيقاف المؤقت، اكتب <code>/reload-plugins</code> أو أعد تشغيل Claude Code. ولإزالة متجر الإضافات الذي أضفته عند التثبيت أيضًا: <code>/plugin marketplace remove cursor-plugins</code>. انتبه إلى أن هذا يلغي أيضًا تثبيت كل الإضافات الأخرى المثبّتة من ذلك المتجر.</p>
</div>

## بعد التحديث: أعد تشغيل الإعداد

يكتب `/setup-pstack` النماذج في ملف الإعدادات حسب <Term k="模型角色" />، سطرًا لكل دور. إذا غيّر إصدار جديد النماذج الافتراضية، يظل ملفك يذكر النماذج القديمة. <mark>عندما تقرأ أي مهارة ذلك السطر، تستمر في استخدام النموذج القديم</mark>.

<Cmd c="/setup-pstack" />

يتعرّف الأمر على القيم الافتراضية القديمة، ويضع الجديدة مكانها، ويخبرك أيها تغيّر. وتبقى النماذج التي اخترتها بنفسك كما هي. إذا كان إصدار أقدم قد كتب الملف، يذكّرك `/poteto-mode` مرة واحدة في كل محادثة.

إذا وُجدت قيمة قديمة لا يتعرّف عليها، فافتح ملف الإعدادات واحذف ذلك السطر (أو الملف كاملًا) أولًا، ثم أعد تشغيل الأمر.

| الأداة | ملف الإعدادات |
| --- | --- |
| Cursor | `~/.cursor/rules/pstack-models.mdc` |
| Claude Code | `~/.claude/rules/pstack-models.md` |
| Codex وغيرها | `~/.agents/pstack-models.md` |

<Callout type="ok" title="إعادة التشغيل آمنة">
عندما تعيد تشغيل `/setup-pstack`، تبقى الأدوار التي غيّرتها بنفسك كما هي. ابدأ محادثة جديدة بعد ذلك، وإلا فلن تُطبَّق التغييرات.
</Callout>

## بعد إلغاء التثبيت: احذف ملف الإعدادات أيضًا

إلغاء التثبيت لا يحذف ملف الإعدادات. يقرؤه Claude Code في كل جلسة جديدة، فيشغل مساحة بلا فائدة. إذا لم تعد تستخدم pstack، فاحذف ذلك الملف الوارد في الجدول أعلاه أيضًا.

إذا أنشأ pstack <Term k="验证技能" /> (مجلدًا مثل `verify-your-app`)، فهي تخصّ مشروعك ولا تُحذف معه.

## توقفت عند خطوة؟

<Q q="أجريت التحديث، لكنه ما زال يستخدم النماذج القديمة.">
السبب على الأرجح هو ملف الإعدادات القديم. أعد تشغيل `/setup-pstack`. إذا لم يحلّ ذلك المشكلة، فاحذف سطر ذلك الدور. ثم ابدأ محادثة جديدة.
</Q>
<Q q="لا تظهر مهارات pstack في npx skills list.">
تأكّد من أنك تشغّل الأمر داخل مجلد المشروع الذي أجريت فيه التثبيت. المهارات المثبّتة داخل مشروع وتلك المثبّتة بـ `-g` توجد في مكانين مختلفين.
</Q>
