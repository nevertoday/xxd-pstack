## Befehle nach Installationsweg

Wähl den Tab für den Befehl, den du damals eingegeben hast:

- `npx skills add` → Skills-Kommandozeile
- `/plugin install` → Claude-Code-Plugin
- `/add-plugin` → Cursor-Plugin

Weißt du es nicht mehr? Wenn Befehle das Präfix `pstack:` brauchen, ist es das Claude-Code-Plugin.

<p>Führ diese Befehle im Terminal aus (nicht im Chatfeld der KI):</p>
<p><Cmd c="npx skills list" /> Installierte Skills anzeigen.</p>
<p><Cmd c="npx skills check" /> Auf neue Versionen prüfen.</p>
<p><Cmd c="npx skills update" /> Auf die neueste Version aktualisieren.</p>

## Nach dem Update: Setup erneut ausführen

`/setup-pstack` schreibt das Modell für jede <Term k="模型角色" /> in die Einstellungsdatei, jeweils eine Zeile. Ändert eine neue Version die Standardmodelle, stehen in deiner Datei noch die alten. <mark>Wenn ein Skill diese Zeile liest, nutzt er weiter das alte Modell</mark>.

<Cmd c="/setup-pstack" />

Es erkennt alte Standardwerte, tauscht sie gegen die neuen aus und sagt dir, welche. Modelle, die du bewusst gewählt hast, bleiben erhalten. Wenn eine ältere Version die Datei geschrieben hat, erinnert dich `/poteto-mode` einmal pro Chat daran.

Erkennt es einen alten Wert nicht, öffne zuerst die Einstellungsdatei, lösch diese Zeile (oder die ganze Datei) und führ den Befehl dann aus.

| Tool | Einstellungsdatei |
| --- | --- |
| Cursor | `~/.cursor/rules/pstack-models.mdc` |
| Claude Code | `~/.claude/rules/pstack-models.md` |
| Codex und andere | `~/.agents/pstack-models.md` |

<Callout type="ok" title="Erneutes Ausführen ist sicher">
Wenn du `/setup-pstack` erneut ausführst, bleiben Rollen erhalten, die du bewusst geändert hast. Starte danach einen neuen Chat, sonst greift es nicht.
</Callout>

## Nach dem Deinstallieren: auch die Einstellungsdatei löschen

Beim Deinstallieren wird die Einstellungsdatei nicht gelöscht. Claude Code liest sie in jeder neuen Sitzung ein – sie nimmt also nur Platz weg. Wenn du pstack nicht mehr brauchst, lösch auch diese Datei aus der Tabelle oben.

Ein <Term k="验证技能" />, den es erstellt hat (ein Ordner wie `verify-your-app`), gehört zu deinem Projekt und wird nicht mit pstack entfernt.

## Kommst du nicht weiter?

<Q q="Ich habe aktualisiert, aber es nutzt immer noch die alten Modelle.">
Höchstwahrscheinlich liegt es an der alten Einstellungsdatei. Führ `/setup-pstack` erneut aus. Wenn das nicht hilft, lösch die Zeile für diese Rolle. Starte dann einen neuen Chat.
</Q>
<Q q="Ich sehe die Skills von pstack nicht in npx skills list.">
Achte darauf, dass du den Befehl in dem Projektordner ausführst, in dem du installiert hast. Im Projekt installierte Skills und mit `-g` installierte Skills liegen an verschiedenen Orten.
</Q>
