## Install for your tool

<div data-sk-keep>
<Tabs id="install" label="Choose your tool" items={[["cc", "Claude Code"], ["cursor", "Cursor"], ["other", "Codex and others"]]}>
<div slot="cc">

In Claude Code's chat box, send these two in order:

<Copy id="cc-1" title="First: add the plugin marketplace" code="/plugin marketplace add cursor/plugins" />
<Copy id="cc-2" title="Second: install pstack" code="/plugin install pstack@cursor-plugins" />

Once it's installed, <mark><strong>every command lives under `pstack:`</strong></mark>. You type `/pstack:poteto-mode`; plain `/poteto-mode` isn't recognized. That's Claude Code's rule for plugins, so two plugins can't clash over a name.

It **doesn't auto-update** by default. To turn it on: type `/plugin`, open the "marketplaces" tab, choose `cursor-plugins`, then choose "enable auto-update".

Don't want the prefix? Install with `npx skills` from the "Codex and others" tab instead.

</div>
<div slot="cursor">

In Cursor's chat box, send:

<Copy id="cursor-1" code="/add-plugin pstack" />

Commands keep their plain names, like `/poteto-mode` and `/how`. No prefix needed.

Optional: also install the `cursor-team-kit` plugin. pstack uses it in a few places. It works fine without it.

</div>
<div slot="other">

Open a terminal **in your project folder** and run:

<Copy id="npx-1" lang="bash" title="Install into this project" code="npx skills add backnotprop/pstack" />

It lists every skill. **The first time, select all**, then pick which tools to install into. To slim it down later, see [Installing only a few skills](/en/howto/pick-skills/).

To make it available in every project, add `-g`:

<Copy id="npx-2" lang="bash" title="Install globally" code="npx skills add backnotprop/pstack -g" />

It needs Node.js 22.20 or later. Not sure? Run `node -v` to check.

</div>
</Tabs>
</div>

Once it's installed, pick your tool here. Every command on the site, including what the copy buttons copy, switches to how that tool writes it:

## Test it

Start a **new** conversation and send:

<Copy id="test" title="Quick test" code="/poteto-help Which pstack skill should a beginner learn first? Answer in one or two sentences." />

If the answer mentions poteto-mode, you're installed. `/poteto-help` only answers questions. It won't start working on anything.

<Callout type="ok">
Type `/` in the chat box, and you can find `poteto-mode` in the menu that pops up (`pstack:poteto-mode` with the Claude Code plugin).
</Callout>

## Stuck?

<Q q="I type / and can't find poteto-mode.">
<p>Start a new conversation first. Still missing? With the Claude Code plugin, search for <code>pstack:</code>. If you used <code>npx skills</code>, make sure the tool is open in <strong>the project folder you installed into</strong>, or reinstall globally with <code>-g</code>.</p>
</Q>
<Q q="npx skills says my Node version is too old.">
<p>It needs Node.js 22.20 or later. Install a new LTS version from <a href="https://nodejs.org">nodejs.org</a>, then run it again.</p>
</Q>
<Q q="Can I install both the plugin and the npx version?">
<p>Don't. Two copies of the same skill get confusing. Pick one.</p>
</Q>

To update or uninstall later, see [Update, inspect, uninstall](/en/howto/update-remove/).
