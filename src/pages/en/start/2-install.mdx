Open Claude Code the way you usually do, and work in the box where you chat with the AI. There are three steps.

<Fig id="l2-install" />

## Step 1: tell it where to find pstack

Copy this line, paste it into the box, and press Enter:

<Cmd c="/plugin marketplace add cursor/plugins" />

This adds Cursor's "plug-in store." pstack lives there, and Claude Code can install from it too.

<Callout type="ok">
You see `Successfully added marketplace: cursor-plugins`. The store was added.
</Callout>

## Step 2: install pstack

Copy this line and press Enter:

<Cmd c="/plugin install pstack@cursor-plugins" />

pstack's details open on screen, with three options below asking who it's for.

Use the ↑ ↓ arrow keys to pick the first one, **Install for you** (works in any folder), and press Enter.

<Callout type="ok">
The last line says `Plugin is now active.` If it says `Run /reload-plugins to apply` instead, do what it says: type `/reload-plugins` and press Enter.
</Callout>

## Step 3: check that it's installed

Type `/pstack:` in the box, and **don't press Enter yet**.

<Callout type="ok">
A list of commands that start with `pstack:` pops up, and `/pstack:poteto-mode` is one of them. If you see it, you're done. Press Esc to close the list.
</Callout>

## From now on, commands start with pstack:

A plugin install puts every pstack command under `pstack:`. You type `/pstack:poteto-mode`; plain `/poteto-mode` isn't recognized. That's Claude Code's rule for all plugins, so two plugins can't clash over a name.

No need to memorize it. Commands on this site are written that way by default, so you can copy them as they are. Not using Claude Code? Pick your tool here and every command on the site changes to match:

<ToolPick />

Nothing else needs setting up. It works as soon as it's installed.

## If something's off

<Q q="When I type /plugin, it says the command doesn't exist.">

Your Claude Code is too old. Update it first:

1. Type `/exit` and press Enter to quit Claude Code.
2. In the same window, type `claude update`, press Enter, and wait for it to finish.
3. Type `claude` and press Enter to open it again. Start over from step 1.


</Q>
<Q q="Step 2 says it can't find pstack.">
<p>Step 1 probably didn't work. Type the step 1 line again, wait for `Successfully added marketplace`, then do step 2.</p>
</Q>
<Q q="Nothing pops up when I type /pstack:.">

First, reopen it: type `/exit` to quit, type `claude`, then try `/pstack:` again.

Still missing? Type `/plugin` and press Tab to get to the Installed page. Check that pstack is there and turned on.


</Q>
<Q q="I use Cursor, not Claude Code.">
<p>Type `/add-plugin pstack` in Cursor's chat box and it's installed. Commands in Cursor have no `pstack:` prefix: pick Cursor under "I use" above, and the next lesson's commands switch to how Cursor writes them.</p>
</Q>

## If you stop using it

Type this line in the box and press Enter to uninstall pstack:

<Cmd c="/plugin uninstall pstack@cursor-plugins" />

Then type `/reload-plugins` and press Enter (or reopen Claude Code), and the `/pstack:` commands are gone. To install it again later, start over from step two. To pause it for a while instead, use `disable` in place of `uninstall`, and `enable` when you want it back.
