## pstack 是什么

pstack 是一包<Term k="技能" />，装进你已经在用的 AI 编程工具里，比如 Claude Code、Cursor 或 Codex。

装上以后，AI 写代码会按资深工程师的规矩来：<mark><strong>先搞懂，再动手，改完自己检查。</strong></mark>

模型还是那个模型。变的是它做事的顺序和标准。

<Fig id="g0-layers" />

## 它改掉哪些毛病

- **没读懂就改。** 改在看着对、其实不对的地方。
- **只治表面。** 在显示的地方去掉重复数据，产生重复的 bug 还在。
- **没试过就说做完了。** 它说「应该没问题了」，你一跑还是坏的。
- **越改越多。** 加一堆用不上的代码，下一个 bug 就藏在里面。

## 你只要记住一个命令

平时只打 `/poteto-mode`。你说目标，它安排剩下的。它背后还有这些，先不用学：

- **23 套<Term k="剧本" />**：修 bug、加功能、重构……每类任务一套做法。
- **34 个技能**：比如 `/how` 讲清代码，`/bro` 翻成大白话。见[技能速查](/skills/)。
- **24 条<Term k="原则" />**：比如「先删再加」「证明它能用」。
- **2 个帮手 AI**：一个被派出去干活时也守同样的规矩，一个专门审注释。

## 用了有什么好处

- **改动更小，改完都试过。** 能删就删；收尾时跑真命令、点真界面。
- **能放心同时开几个 AI。** 每个都守同一套规矩，各用各的工作目录。
- **同样的错不犯第二次。** 用 `/correct` 从根上堵住。

<Callout type="warn" title="代价：更慢、更费钱">
它会多派帮手 AI、让几个模型互相检查，所以更慢、更费 token。小改动不用它。省钱见[控制花费](/howto/cost/)。
</Callout>

## 开始前准备四样东西

- **一个 AI 编程工具**：Claude Code、Cursor、Codex 任选一个（OpenCode、Pi 也行）。它要能改你的代码、能执行命令。<u>只能聊天的网页版 AI 不行</u>。
- **能用的模型**：工具的付费订阅，或者 API。
- **一个放在 Git 里的真实项目**：大部分剧本会建 <Term k="worktree" />、开 <Term k="PR" />。还没用 Git 的，先 `git init` 提交一次。
- **Node.js 22.20 以上**：只有用 `npx skills` 安装才需要。

本站用的是 [backnotprop/pstack](https://github.com/backnotprop/pstack) 镜像：每天和官方版同步，Claude Code、Codex 也能用。用法一样。
</Callout>
