## 按你的工具装

<Tabs id="install" label="选择你的工具" items={[["cc", "Claude Code"], ["cursor", "Cursor"], ["other", "Codex 和其他"]]}>
<div slot="cc">

在 Claude Code 的对话框里，依次发这两条：

<Copy id="cc-1" title="第一条：添加插件市场" code="/plugin marketplace add cursor/plugins" />
<Copy id="cc-2" title="第二条：安装 pstack" code="/plugin install pstack@cursor-plugins" />

装好以后，<mark><strong>所有命令前面都要加 `pstack:`</strong></mark>。`/poteto-mode` 要打成 `/pstack:poteto-mode`。本站其他页面都省略了它，你用时记得加。

它默认**不自动更新**。想打开：输入 `/plugin`，打开「marketplaces」标签，选 `cursor-plugins`，再选「enable auto-update」。

不想打前缀，也可以用「Codex 和其他」里的 `npx skills` 装。

</div>
<div slot="cursor">

在 Cursor 的对话框里发：

<Copy id="cursor-1" code="/add-plugin pstack" />

命令就是原样的 `/poteto-mode`、`/how`，不用加前缀。

可选：再装 `cursor-team-kit` 插件，pstack 有几处会用到。不装也行。

</div>
<div slot="other">

在**你的项目目录**里打开终端，运行：

<Copy id="npx-1" lang="bash" title="装进当前项目" code="npx skills add backnotprop/pstack" />

它会列出所有技能。**第一次用，全选**，再选要装进哪些工具。以后想精简，见[只装几个技能](/howto/pick-skills/)。

想让所有项目都能用，加 `-g`：

<Copy id="npx-2" lang="bash" title="装到全局" code="npx skills add backnotprop/pstack -g" />

需要 Node.js 22.20 以上。不确定就先运行 `node -v` 看看。

</div>
</Tabs>

## 装完测一下

开一个**新的**对话，发：

<Copy id="test" title="测试一下（Claude Code 插件版写成 /pstack:poteto-help）" code="/poteto-help pstack 里新手最该先学哪个技能？用一两句话回答。" />

回答里提到 `/poteto-mode`，就是装好了。`/poteto-help` 只回答问题，不会开始干活。

<Callout type="ok">
在对话框里输入 `/`，弹出的菜单里能找到 `poteto-mode`（Claude Code 插件版是 `pstack:poteto-mode`）。
</Callout>

## 卡住了？

<Q q="输入 / 之后找不到 poteto-mode。">
<p>先开一个新对话。还找不到：Claude Code 插件版搜 <code>pstack:</code>；用 <code>npx skills</code> 装的，确认工具是在<strong>装的那个项目目录</strong>里打开的，或者加 <code>-g</code> 重装到全局。</p>
</Q>
<Q q="npx skills 报错说 Node 版本太低。">
<p>它要 Node.js 22.20 以上。到 <a href="https://nodejs.org">nodejs.org</a> 装一个新的 LTS 版本，再运行一次。</p>
</Q>
<Q q="插件版和 npx 版能一起装吗？">
<p>不要。同一个技能有两份容易混，选一种就好。</p>
</Q>
