## 这一步做什么

把 pstack 装进你的 AI 编程工具（也叫<Term k="宿主" />）。只有一两条命令，装完用一句话测一下。

有两种装法，看你用什么工具：

- **插件**：Cursor 和 Claude Code 都有插件市场，装的是 Cursor 官方维护的版本，连同两个子代理一起装好。
- **`npx skills`**：一个通用的技能安装工具，支持 Claude Code、Codex、Cursor、OpenCode 等几十种工具。装的是 backnotprop 镜像版，可以在列表里挑着装。

## 按你的工具装

<Tabs id="install" label="选择你的工具" items={[["cc", "Claude Code"], ["cursor", "Cursor"], ["other", "Codex 和其他"]]}>
<div slot="cc">

**推荐用插件装**，在 Claude Code 的对话框里依次输入：

<Copy id="cc-1" title="第一条：添加插件市场" code="/plugin marketplace add cursor/plugins" />
<Copy id="cc-2" title="第二条：安装 pstack" code="/plugin install pstack@cursor-plugins" />

装好以后，<mark><strong>所有命令前面都要加 `pstack:` 前缀</strong></mark>：`/poteto-mode` 要打成 `/pstack:poteto-mode`，`/setup-pstack` 要打成 `/pstack:setup-pstack`。这是 Claude Code 给插件命令加的前缀，本站其他页面为了好读都省略了，你自己用时记得加。

Claude Code 对第三方插件市场默认**不自动更新**，pstack 会一直停在你装的那个版本。想自动更新：输入 `/plugin`，打开「marketplaces」标签，选 `cursor-plugins`，选「enable auto-update」。

也可以用下面「Codex 和其他」里的 `npx skills` 装，好处是命令不带前缀、能只挑几个技能装。

</div>
<div slot="cursor">

在 Cursor 的对话框里输入：

<Copy id="cursor-1" code="/add-plugin pstack" />

Cursor 会提示装好了。命令名就是原样的 `/poteto-mode`、`/how`，不用加前缀。

Cursor 用户还可以顺手装 `cursor-team-kit` 插件：pstack 有几处会用到它里面的 `/deslop`（清理代码里的 AI 痕迹）和 `control-cli`、`control-ui`（操作命令行和浏览器）。不装也能用，pstack 会改用别的办法。

</div>
<div slot="other">

在**你的项目目录**里，打开终端运行：

<Copy id="npx-1" lang="bash" title="装进当前项目" code="npx skills add backnotprop/pstack" />

它会列出 pstack 的全部技能（可以搜索），先选技能，再选要装进哪些工具。**第一次用，技能全选**；以后想精简，见[只装几个技能](/howto/pick-skills/)。

默认只装进当前项目。想让所有项目都能用，加 `-g`：

<Copy id="npx-2" lang="bash" title="装到全局" code="npx skills add backnotprop/pstack -g" />

要求 Node.js 22.20 或更高版本。不确定的话先运行 `node -v` 看一下。

</div>
</Tabs>

## 装完测一下

开一个**新的**对话，发一句：

<Copy id="test" title="测试一下（Claude Code 插件版写成 /pstack:poteto-help）" code="/poteto-help pstack 里新手最该先学哪个技能？用一两句话回答。" />

`/poteto-help` 是 pstack 的问路处：它只回答问题、给你一段可以直接发的提示词，**不会开始干活**。它回答里提到 `/poteto-mode`，就说明装好了。

<Callout type="ok">
在对话框里输入 `/`，弹出的菜单里能找到 `poteto-mode`（Claude Code 插件版是 `pstack:poteto-mode`）。
</Callout>

## 卡住了？

<Q q="输入 / 之后找不到 poteto-mode。">
<p>先开一个新对话，技能列表通常是对话开始时加载的。还找不到：Claude Code 插件版要搜 <code>pstack:</code>；用 <code>npx skills</code> 装的，确认你是在<strong>装的那个项目目录</strong>里打开的工具，或者重新用 <code>-g</code> 装到全局。</p>
</Q>
<Q q="npx skills 报错说 Node 版本太低。">
<p>它要求 Node.js 22.20 以上。到 <a href="https://nodejs.org">nodejs.org</a> 装一个新的 LTS 版本，再运行一次。</p>
</Q>
<Q q="插件版和 npx 版能一起装吗？">
<p>别一起装，同一个技能出现两份容易混。选一种就好。</p>
</Q>
