## 钱花在哪了

同一件事，用 `/poteto-mode` 做要多花不少 <Term k="token" />（AI 的额度）。多在三处：

- **派出去的帮手 AI。** 读代码、写代码会分给几个<Term k="子代理" />，每个都单独花钱。
- **评审组。** `arena`、`architect`、`interrogate` 会让几个模型各做一遍。默认两个，就是两份钱。
- **想得久。** 默认档位 `xhigh`，想得越久越贵。

这些钱换来的是检查和第二意见。下面几招少花一点，又不丢掉它们。

## 小事别开 /poteto-mode

改错别字、调颜色、加一行日志，一眼能看出对不对，直接说就行。

- **只想问怎么做**：用 `/poteto-help`。它只回答，不干活。
- **没看懂代码**：先问 `/how`，比改错了再返工便宜。

## 主对话用强的，写代码用便宜的

<mark>你直接对话的主对话用强模型；写代码的那几个角色换成便宜的模型。</mark>

主对话要读懂你、审改动，省了容易出错。写代码的帮手拿到的是说清楚的活，便宜模型也做得好。

跑 `/setup-pstack`，到最后「确认角色」时，把 `feature, refactoring`、`bug-fix`、`perf-issue` 这几行换成更便宜的模型。

## 降一档预算

<Cmd c="/setup-pstack" />

（Claude Code 里是 `/pstack:setup-pstack`。）它会给你四档：

| 预算 | 档位 | 说明 |
| --- | --- | --- |
| `unlimited` | 最高到 `max` | 最贵 |
| `large` | `xhigh` | 就是默认 |
| `medium` | `high` | 便宜一点 |
| `small` | `medium` | 最省 |

预算只改「想多久」，不换模型。你自己改过的角色会保留。<u>选完要开一个新对话</u>，才会生效。

<Callout type="tip" title="它本来就会看活定档位">
预算只是起点。最难的活它会升一档，例行杂活会降两档以上。所以就算在 `large`，简单的活也不按最高价算。
</Callout>

## auto 和 inherit-parent：跟着主对话走

给角色填 `auto` 或 `inherit-parent`，意思一样：不指定模型，跟主对话用同一个。`auto` 不是一个叫 auto 的模型。

主对话便宜，这些角色就跟着便宜。Claude Code 里写代码的角色默认就是它。

## 卡住了？

<Q q="改成 small 以后，结果明显变差了。">
先试 `medium`。或者保留 `large`，只把写代码的角色换成便宜模型。判断出错的代价，通常比省下的钱大。
</Q>
<Q q="我手改了设置文件里的模型名，它说用不了。">
名字可能拼错了，或者你没有权限。它会退回默认模型，并说一声。想换模型，重跑 `/setup-pstack`，从列出的里面选。
</Q>
<Q q="改了预算，花费没变。">
新设置只对新对话生效，开一个新对话再看。用 Codex 这类工具的，确认 `~/.agents/pstack-models.md` 真的写出来了。
</Q>
