## 按装法找命令

按你当初输入的命令选：

- `npx skills add` → skills 命令行
- `/plugin install` → Claude Code 插件
- `/add-plugin` → Cursor 插件

记不清的话：命令要带 `pstack:` 前缀的，是 Claude Code 插件。

<Tabs id="ur" items={[["skills","skills 命令行"],["cc","Claude Code 插件"],["cursor","Cursor 插件"]]}>
<div slot="skills">
<p>在终端里运行（不是在 AI 对话框里）：</p>
<p><Cmd c="npx skills list" /> 看装了哪些技能。</p>
<p><Cmd c="npx skills check" /> 检查有没有新版本。</p>
<p><Cmd c="npx skills update" /> 更新到最新。</p>
<p><Cmd c="npx skills remove" /> 卸载技能。</p>
<p>不加 <code>-g</code> 装的，只在当时那个项目里。</p>
</div>
<div slot="cc">
<p>第三方插件默认不自动更新。手动更新一次：</p>
<p><Cmd c="claude plugin update pstack@cursor-plugins" /></p>
<p>想自动更新：输入 <code>/plugin</code>，打开 <strong>marketplaces</strong> 标签页，选中 <code>cursor-plugins</code>，再选 <strong>enable auto-update</strong>。查看和卸载也在 <code>/plugin</code> 里。</p>
</div>
<div slot="cursor">
<p>在侧边栏的 Customize 里管理。pstack 没写 Cursor 插件的更新步骤，以 Cursor 的界面为准。</p>
</div>

## 更新以后：清掉旧默认

`/setup-pstack` 会把每个<Term k="模型角色" />的模型一行一行写进设置文件。新版本换了默认模型，你的文件里写的还是旧的。<mark>技能读到这一行，就照旧用旧模型</mark>。

二选一：

1. 打开设置文件，删掉你没特意改过的那些行。删掉的角色会用新的默认。
2. 把整个文件删了，再跑一次 `/setup-pstack`。

| 工具 | 设置文件 |
| --- | --- |
| Cursor | `~/.cursor/rules/pstack-models.mdc` |
| Claude Code | `~/.claude/rules/pstack-models.md` |
| Codex 等 | `~/.agents/pstack-models.md` |

<Callout type="ok" title="放心重跑">
重跑 `/setup-pstack`，你特意改过的角色会保留。改完开一个新对话，才会生效。
</Callout>

## 卸载以后：把设置文件也删掉

卸载不会删设置文件。Claude Code 每个新会话都会读它，白占地方。彻底不用了，把上面表里那个文件也删掉。

生成过的<Term k="验证技能" />（`verify-你的应用` 这类文件夹）属于你的项目，不会跟着卸掉。

## 卡住了？

<Q q="更新完了，用的还是老模型。">
多半是旧设置文件。删掉那个角色的行，或者重跑 `/setup-pstack`，再开一个新对话。
</Q>
<Q q="npx skills list 里看不到 pstack 的技能。">
确认你在当初安装的项目文件夹里运行。装在项目里的和用 `-g` 装的，不在同一个地方。
</Q>
