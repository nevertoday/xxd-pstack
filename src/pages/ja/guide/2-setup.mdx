## このコマンドを 1 つ送ります

<Copy id="setup" code="/setup-pstack" />

使えるモデルを確認してから、いくつか質問してきます。回答は設定ファイルに保存されます。それ以降は、すべてのスキルがこのファイルをもとにモデルを選びます。

## 予算を聞かれたら：迷ったら large を選びます

<Term k="推理预算" />は、モデルが考えられる時間の長さです。長いほど丁寧になりますが、コストも高くなります。

| 選択肢 | 推論レベル | 目安 |
| --- | --- | --- |
| `large` | xhigh（デフォルト） | 迷ったらこれ |
| `medium` | high | 少し節約したいとき |
| `small` | medium | 簡単な作業、予算を抑えたいとき |

`large` が最大の予算です。pstack のどの役割も、xhigh より上では動きません。

## 役割ごとのモデルを聞かれたら：デフォルトのままにします

<Term k="模型角色" />ごとに、別のモデルを使えます。

- **コーディング・文章作成・判断の役割**：デフォルトは opus 5.5 です。
- **レビューパネル**：デフォルトでは fable 5.2、opus 5.5、gemini 4 neon が 1 席ずつ入ります。お互いのミスを見つけられるよう、あえて別々のモデルにしています。

いちばん高価な fable 5.2 は、普段は使われません。レビューパネル以外で動くのは、名指しで指定したときか、opus 5.5 が同じ作業に 2 回失敗したときだけです。

気になる役割だけ変えてください。`auto` や `inherit-parent` は「メインの会話と同じモデルを使う」という意味です。

<Callout type="tip" title="Claude Code を使っている場合">
Claude Code では、ヘルパーの AI は Claude モデルしか使えません。レビューパネルの gemini 枠には、代わりに現在の会話で使っているモデルが入ります。すぐに使える 3 つの設定例は、[Claude Code での使い方](/ja/howto/claude-code/#うまく設定するコツ)を見てください。
</Callout>

## 検証スキルを聞かれたら：初心者なら「はい」と答えます

「アプリが本当に動く」と確かめる手段がプロジェクトにまだない場合、<Term k="验证技能" />を作るか提案してきます。

<strong>初心者なら、「はい」と答えてください。</strong>自分の作業を自分で確認できる AI は、確認が通るまで作業を続けます。手で確認する必要はありません。

<Term k="形式化验证" />スキルについても聞かれることがあります。並行処理やリトライなど、テストしにくい箇所がコードにある場合だけ「はい」と答えてください。あとから追加できます。

## 終わったら、新しい会話を始めます

設定ファイルは次の場所に書き込まれます。

- **Cursor**：`~/.cursor/rules/pstack-models.mdc`
- **Claude Code**：`~/.claude/rules/pstack-models.md`
- **Codex やその他のツール**：`~/.agents/pstack-models.md`

Cursor と Claude Code がこのファイルを読み込むのは、新しい会話を始めたときだけです。そのため、<mark>設定が終わったら、この会話を閉じて新しい会話を始めてください</mark>。

## つまずいたときは？

<Q q="あとからモデルや予算を変えたいときは？">
<p>もう一度 <code>/setup-pstack</code> を実行してください。変更した役割はそのまま残ります。ある役割をデフォルトに戻したい場合は、設定ファイルからその行を削除します。</p>
</Q>
<Q q="pstack のデフォルトモデルが更新されたのに、自分の設定が変わりません。">
<p>以前の設定ファイルに古い値が残っているためです。もう一度 <code>/setup-pstack</code> を実行してください。認識できる古いデフォルト値を新しいものに置き換え、どこを変えたかも教えてくれます。自分で選んだ設定はそのまま残ります。認識できない古い値がある場合は、その行（またはファイル全体）を先に削除してください。</p>
</Q>
<Q q="検証スキルを「いいえ」にしましたが、やっぱり使いたくなりました。">
<p><code>/create-verification-skill</code> を実行してください。詳しくは<a href="/ja/guide/6-verify-ship/">ステップ 6</a> を見てください。</p>
</Q>
