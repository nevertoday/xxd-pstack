## まず、信頼できる状態か確かめる

手を放す前に、次の 4 つがすべてそろっている必要があります。

1. **良い仕上がりがわかっている**：自分で一度やったか、やるところを一度見たことがあります。
2. **自分が使うツールを AI も持っている**：検証スキルやログです。
3. **どのステップも自分で正しさを証明できる**：基準に届かなければ止まります。
4. **繰り返すミスにはチェックが入っている**：会話ログをいくつか読んでいます。

<mark>4 つすべてがそろうまでは、見ている前で走らせてください。</mark>

## 寝る前の指示を書く

<Copy id="contract" title="寝る前の指示" code={`/poteto-mode これから寝ます。main から新しい worktree を切って、すべての呼び出し元を新しいパーサーへ移行してください。
完了条件：古い呼び出し元が残っていないこと、パーサーのフィクスチャがすべて通ること、古い API が削除されていること。
判断ログを残してください。コミット前の確認は不要です。
/loop until done. 何時間も詰まって本当に進めなくなったら、そこで止めて理由を書き残してください。`} />

それぞれの文の役割は次のとおりです。

- **これから寝ます**：質問せず、そのまま進めるよう伝えます。
- **完了条件**：毎ラウンドこの条件をチェックします。
- **新しい <Term k="worktree" />**：自分の作業とは切り離された別の作業フォルダです。
- **コミット前の確認は不要**：こちらの OK を待って止まることがなくなります。
- **/loop until done**：終わったかどうかを繰り返しチェックし続けます（Cursor と Claude Code に組み込まれています）。
- **詰まったら止めて理由を書く**：8 時間むだな作業を続けるより、止まるほうがましです。

<Callout type="no" title={`「4 時間作業する」は完了条件になりません`}>
時間の長さは確かめられません。通ったか落ちたかがはっきりわかる条件を渡してください。
</Callout>

## 朝になったら：まず「要確認」を読む

<Copy id="audit" code="/show-me-your-work 昨夜やったことを順に説明してください" />

**返ってくるもの**：まとめです。結果を返す前に、他社のモデルがログを読み、「要確認」セクションを付け足します。<strong>まずそのセクションを読み、次にそこで示されている行を確認してください。</strong>

ログは `decisions.tsv` です（複数のタスクで 1 つのフォルダを共有している場合は `.audit/<task-name>.tsv`）。デフォルトでは手元のマシンに残ります。

進捗だけ知りたいですか？そのチャットで `/ketchup` と入力します。何が変わったかと、こちらの判断待ちになっていることを教えてくれます。

## 一晩に複数の作業を任せる

<Copy id="autopilot" code="/poteto-mode この 5 つの変更を Autopilot で進めてください。ただしマージはしないでください。朝に自分でマージします。" />

| 手元の作業 | 進め方 | 朝の状態 |
| --- | --- | --- |
| 互いに関係のない多数の PR（プルリクエスト） | Autopilot-full | 検証を通ったものがマージ済み |
| 同じく、マージは自分で行う | Autopilot-stack | 検証済みの PR が並んだ状態 |
| 数日がかりのプロジェクト | `/figure-it-out` に任せる | 各フェーズが進み、判断ログも残っている |

## つまずいたときは？

<Q q="勝手にコミットさせるのは不安です。">
<p>「コミット前の確認は不要です」を削るか、検証が終わったところで止まる Autopilot-stack を使ってください。</p>
</Q>
<Q q="朝起きたら、同じところをぐるぐる回っていました。">
<p>たいていは、完了条件が十分にはっきりしていなかったのが原因です。<code>/reflect</code> で学びを記録し、<code>/correct</code> で繰り返すミスをチェックに変えてください。</p>
</Q>
<Q q="途中で止めたいです。">
<p>「一時停止」または「オフラインになります」と伝えてください。現在のステップを区切りよく終わらせ、再開用のメモを書き残します。新しいチャットでそこから続きを始められます。</p>
</Q>
