## こんなこと、ありませんでしたか

AI に小さなウェブページや、ブラウザの小さな拡張機能を頼みます。すぐに返事が来ます。「できました！」

開いてみると、ボタンを押しても何も起きません。「まだ動かない」と何度か言っても、変わりません。

理由はシンプルです。**「できました」と言う前に、AI は自分で開いて見ていなかったのです。**

## pstack で、AI が頼れる職人さんのように動きます

水が漏れる蛇口の修理を頼んだところを想像してください。

- 頼りない人は、何回かひねって「直りました」と言って帰ります。
- 頼れる人は、まず水を出して、どこから漏れているかを確かめます。直したあと、もう一度水を出して、漏れていないことをあなたの目で見てもらいます。そこで初めて作業が終わります。

pstack は、AI に入れる「頼れる職人さんの心得」です。入れると、AI に 3 つの習慣がつきます。

1. **頼まれたことを言い直す。** あなたが何をしたいのかを、自分の言葉で言います。違っていたら、すぐに直せます。
2. **何かを変える前に、問題がどこにあるかを見つける。**
3. **終わる前に、自分で試す。** そして、試した結果をスクリーンショットなどで見せてくれます。

コードが書けない方にいちばん役立つのは 3 つ目です。<mark><strong>コードはわからなくて大丈夫。試した結果を見ればいいのです。</strong></mark>

## 用意するもの

- **Claude Code。そして、その中で AI とチャットできること。** まだ入れていない方は、先に [Claude Code の公式クイックスタート](https://code.claude.com/docs/ja/quickstart) を見て入れてから戻ってきてください。
- **Claude の有料プラン。** Claude Code を使うには、もともと必要です。

これだけです。プログラミングの知識も、ほかのツールの勉強もいりません。

## 少し時間がかかり、プランの利用枠も多めに使います

確認や確かめをたくさんするからです。なので、小さなことには使わなくて大丈夫です。

- **誤字を直す、色を変える**：AI にそのまま頼みましょう。
- **新しいものを作る、何度も起きる問題を直す**：pstack を使いましょう。

<Callout type="tip" title="あと 2 レッスンだけ">
入れる（5 分）、そして最初の作業に使ってみる（10 分）。この 3 レッスンを終えれば使えるようになります。サイトのほかのページは、困ったときに調べるためのものです。今は読まなくて大丈夫です。
</Callout>
