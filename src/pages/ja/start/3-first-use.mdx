このレッスンでは、pstack を使って小さいけれど本物のものを作ります。毎日水を何杯飲んだかを記録するウェブページです。終わるころには、いつもの AI との違いがわかります。

## まず、空のフォルダを作る

1. デスクトップに `water` という名前のフォルダを新しく作ります。
2. Claude Code が開いていたら、`/exit` と入力して終了します。
3. 同じウィンドウでこの 1 行を入力し、Enter を押します。「デスクトップの water フォルダに入る」という意味です。

<Cmd c="cd ~/Desktop/water" />

4. `claude` と入力して Enter を押します。そのフォルダの中で Claude Code が開きます。

新しいフォルダを作る理由：AI は、Claude Code を開いたフォルダの中で作業します。新しい空のフォルダなら、パソコンのほかのものには触れません。

<Fig id="l3-folder" />

## このメッセージを送る

<Copy id="first" title="コピーして入力欄に貼り付け、Enter" code={`/pstack:poteto-mode 毎日飲んだ水の量を記録する小さなウェブページを作ってください。ここは空のフォルダです。必要な準備はお任せします。
できあがりの姿：ページを開いて「1 杯飲んだ」を押すと、今日の杯数が 1 つ増える。閉じてもう一度開いても数字が残っている。最近 7 日間、毎日何杯飲んだかがページに表示される。
終わったら見せてほしいもの：どうやって確かめたか、何をして何が見えたか。できればスクリーンショットも。最後に、ページの開き方を教えてください。`} />

最初の `/pstack:poteto-mode` はスイッチです。これをつけると、AI は pstack のルールに従います。つけないと、いつもどおりに動きます。

残りのメッセージは 3 つのパートだけ。これが pstack の使い方のコツのすべてです。

<mark><strong>やってほしいこと · できあがりの姿 · 終わったら見せてほしいもの</strong></mark>

<Fig id="l3-prompt" />

- **やってほしいこと**：水の量を記録するページ。
- **できあがりの姿**：押すと 1 つ増える、閉じて開き直しても数字が残る、7 日分が見える。これは「どうなったら完成か」を伝えていて、AI はこの 1 つ 1 つを確かめます。
- **終わったら見せてほしいもの**：どう確かめて、何がわかったか。コードは読めないので、あなたにわかるものを見せてもらいましょう。

## 途中で質問してきます

数分ほど作業が続きます。その途中で Claude Code が止まって聞いてきます。このファイルを作っていいですか？このコマンドを実行していいですか？

これは Claude Code があなたを守るしくみです。どの手順にもあなたの OK が必要です。このフォルダは新しく作った空のフォルダなので、**Yes**（はい）を選んでください。

## 返事のどこを見るか

返事はいつもより長く、専門用語がたくさん出てくるかもしれません。わからないところは飛ばして、**印のついた 4 か所だけを見てください**。

<Reply code={`① 目的の理解：水の量を記録するページ。「1 杯飲んだ」を押すと
   今日の杯数が 1 つ増える。閉じて開き直しても数字が残る。
   最近 7 日間が表示される。

② やること
   ☐ このフォルダを準備する
   ☐ ページを作る
   ☐ 確かめる：1 杯足す、閉じて開き直す、7 日分を見る
   ☐ 結果をお渡しする

   …（途中は作業の様子です。飛ばして大丈夫）…

③ 確かめたこと
   ✓ 「1 杯飲んだ」を 3 回押した。今日は 3 杯と表示された
   ✓ ページを閉じて開き直した。3 杯のまま
   ✓ 最近 7 日分の棒が 1 本ずつある。今日の棒がいちばん高い
   ? 確かめられなかったこと：スマホでの見た目（パソコンでしか確認していません）

④ 開き方：water フォルダの index.html をダブルクリック`} />

- **まず ① を見ます。** 正しく理解していますか？違っていたら、「7 日じゃなくて 30 日」のように、そのまま打って直してください。
- **② は、これからやる手順です。** 進むたびにチェックをつけていきます。あなたが管理する必要はありません。
- **③ がいちばん大事です。** 1 行ごとに、何をして何が見えたかが書いてあります。「確かめられなかったこと」の行は、AI が正直に話しているしるしで、良いことです。
- **④ のとおりにして、自分の目で見てください。**

## うまくできたかの見分け方

自分に 3 つ質問してみてください。

- AI が言い直した目的は、自分が思っていたことと同じ？
- 「終わりました」と言ったとき、実際にやった確認と、そこで見えたことが並んでいる？
- 自分で開いてみたら、AI が言ったとおりになっている？

3 つとも「はい」なら、この作業は完了です。

確認の結果がひとつもなく、「できました」としか言っていなければ、まだ終わっていません。こう返しましょう。

<Copy id="no-proof" code="実際に確かめた結果を見せてください。何をして、何が見えたか。「できました」だけでなく、それを教えてください。" />

## 違ったときの伝え方

<Q q="結果が違う。たとえば、押しても数字が変わらない。">
<p>見たことだけを伝えます。たとえば「3 回押したけど、数字は 0 のままでした」。原因は推測しなくて大丈夫です。推測が外れると、AI が違う方向に進んでしまいます。</p>
</Q>
<Q q="返事が長くて、知らない言葉だらけ。">
<p>`/pstack:bro` と打ちます。直前の返事を、やさしい言葉でずっと短く言い直してくれます。</p>
</Q>
<Q q="よくわからない質問をされた。">
<p>こう返します。「私はコードが書けません。やさしい言葉で聞いてください。または、いちばん安全な方法を選んで、その理由を教えてください。」</p>
</Q>
<Q q="頼んでいないことをしているので、止めたい。">
<p>Esc を押すと止まります。それから、してほしいことを伝えます。たとえば「水の記録だけにして、今はほかに何も足さないでください」。</p>
</Q>
<Q q="Windows で、cd の行を打つとフォルダが見つからないと言われる。">
<p>Windows のパソコンによっては、デスクトップが OneDrive の中にあります。代わりに `cd ~/OneDrive/Desktop/water` と打ってみてください。</p>
</Q>
<Q q="Claude のデスクトップアプリを使っていて、cd を打つ場所がない。">
<p>新しいセッションを始めるときに、フォルダを選ぶよう聞かれます。デスクトップの water を選んでください。あとは同じです。</p>
</Q>

## これで使えるようになりました

これから何をするときも、形は同じです。`/pstack:poteto-mode` と、3 つのパート。例をあと 2 つ見てみましょう。

<Copy id="ex-fix" title="何度も起きる問題を直す" code={`/pstack:poteto-mode ブックマークの拡張機能で、保存を押すと、ときどき同じものが 2 つ保存されます。
できあがりの姿：保存を 10 回続けて押しても、リストには 1 つだけ。
終わったら見せてほしいもの：どうやって問題をもう一度起こしたか。直したあと、もう一度試したらどうなったか。`} />

<Copy id="ex-how" title="何も変えずに、しくみだけ知りたい" code="/pstack:how このフォルダの中のものは、どういうしくみで動いていますか？私はコードが書けないので、やさしい言葉で説明してください。" />

2 つ目の例は `/pstack:how` を使っています。説明するだけで、あなたのファイルには手をつけません。変えるかどうか決める前に、まずしくみを知りたいときに使ってください。
