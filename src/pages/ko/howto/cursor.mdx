## 명령어 하나로 설치하기

Cursor 대화창에 이렇게 입력하세요:

<Cmd c="/add-plugin pstack" />

사이드바의 Customize에서 설치해도 같아요. 그런 다음 모델을 고르세요:

<Cmd c="/setup-pstack" />

<Term k="推理预算" />(모델이 얼마나 오래 생각할지)에 대해 물어보고, 각 <Term k="模型角色" />에 모델을 배정한 뒤 `~/.cursor/rules/pstack-models.mdc`에 저장해요.

<Callout type="tip" title="설정 후에는 새 대화를 시작하세요">
<u>이 설정은 새 대화에만 적용돼요</u>. 기존 대화에서 계속 이어 가면 여전히 기본 모델을 써요.
</Callout>

이 사이트의 명령어는 기본적으로 Claude Code 플러그인 기준으로 적혀 있어, Cursor에서는 쓰지 않는 `pstack:` 접두사가 붙어 있어요. 여기서 Cursor를 선택하면 사이트의 모든 명령어가 Cursor 형식으로 바뀌어 바로 복사할 수 있어요:

<ToolPick />

## / 메뉴에서 /poteto-mode 고르기

대화창에 `/`를 입력하고 메뉴에서 `/poteto-mode`를 고른 다음, 할 일을 적으세요:

<Copy id="cursor-first" title="첫 번째 작업" code="/poteto-mode 이 명령어에 --json 플래그를 추가해 주세요. 기존 텍스트 출력은 바이트 단위까지 똑같이 유지해야 해요. 두 출력 모두 검증해 주세요." />

어떤 키로 보내느냐에 따라 달라져요:

- **Enter**: 이번 메시지 하나에만 적용돼요. 몇 턴 지나면 작동하지 않아요.
- **Option+Enter(Mac) 또는 Alt+Enter(Windows)**: <mark><Term k="Custom Mode" />(커스텀 모드)로 바뀌어 모든 턴에서 계속 켜져 있어요</mark>. 모드를 나갈 때까지요.

Custom Mode가 켜져 있으면 다음 메시지부터는 “해 주세요”나 “계속”이라고만 해도 충분해요.

한 가지 일을 마치고 다음으로 넘어갈 때는 “new task”로 시작하세요. 그렇지 않으면 새 질문을 이전 작업의 다음 단계로 받아들여요.

## 자기 전에 맡겨 두기: /loop

`/loop`는 Cursor에 기본으로 들어 있는 명령어예요. 이따금 AI를 깨워서 작업이 끝났는지 확인하게 해요. 통과와 실패가 분명히 갈리는 완료 조건을 주세요:

<Copy id="cursor-loop" title="자기 전에" code={`/poteto-mode 이제 자러 가요. 새 worktree(<기준 브랜치>에서 분기)에서 모든 호출부를 새 파서로 마이그레이션해 주세요.
완료 조건: 예전 호출부가 하나도 남지 않고, 파서 테스트 데이터가 모두 통과하고, 예전 API가 삭제된 상태.
결정 로그를 남겨 주세요. 커밋하기 전에 저한테 물어보지 않아도 돼요.
/loop until done. 몇 시간이 지나도 정말 막히면 멈추고 이유를 적어 두세요.`} />

“4시간 동안 작업해 주세요”는 완료 조건이 아니에요. 확인할 게 없어서, 아침에 일어나면 4시간 치 헛수고만 남아 있을 거예요. 더 자세한 내용은 [알아서 돌아가게 두기](/ko/guide/7-overnight/)를 참고하세요.

## 여러 AI 동시에 쓰기: 각자 공간 나눠 주기

여러 AI가 한 폴더에서 코드를 고치면 서로 작업 내용을 덮어써요. 서로 겹치지 않게 나누는 방법은 두 가지예요:

- **클라우드에서**: 작업 앞에 `/in-cloud`를 붙이세요. AI마다 각자 머신과 브랜치를 쓰고, 내 컴퓨터는 건드리지 않아요.
- **로컬에서**: 작업마다 별도의 <Term k="worktree" />(워크트리, 같은 Git 저장소의 별도 작업 폴더)를 만들어 주세요. 노트북에서는 한 번에 몇 개 정도면 충분해요.

<Copy id="cursor-wt" code={`/poteto-mode new task. <기준 브랜치>에서 새 worktree를 만들고 파서 변경 사항을 거기로 옮겨 주세요.`} />

## 따로 설치할 것 몇 가지

`/poteto-mode`의 일부 단계에서는 `cursor-team-kit` 플러그인을 써요. 없어도 돌아가지만, 그 단계들의 효과가 떨어져요. 모든 기능을 다 쓰려면 설치하세요. 여기에는 다음이 들어 있어요:

- **`deslop`**: 코드에서 “AI 티”를 빼 줘요.
- **`control-cli`**: 명령줄 프로그램을 조작해요.
- **`control-ui`**: 브라우저와 웹 페이지를 조작해요.

pstack에는 계획을 세우는 스킬이 없어요. Cursor에 기본으로 들어 있는 Plan Mode를 함께 쓰세요.

## 막혔나요?

<Q q="몇 턴 지나면 /poteto-mode가 작동하지 않아요.">
Enter로 보냈을 가능성이 커요. 메뉴에서 다시 고른 뒤 Option+Enter(Windows에서는 Alt+Enter)를 누르세요. 아니면 새 작업을 시작할 때마다 `/poteto-mode`를 다시 입력하세요.
</Q>
<Q q="모델 설정을 바꿨는데 여전히 예전 모델로 돌아가요.">
설정은 새 대화에만 적용돼요. 새 대화를 시작해서 다시 해 보세요.
</Q>
<Q q="여러 AI가 동시에 작업하다가 파일이 뒤죽박죽됐어요.">
작업마다 각자 worktree를 만들어 주거나, `/in-cloud`로 클라우드에 맡기세요.
</Q>
<Q q="밤새 /loop를 돌렸는데 끝난 게 하나도 없어요.">
완료 조건은 “이 명령어가 0을 반환함”이나 “이 테스트가 모두 통과함”처럼 통과와 실패가 분명히 갈려야 해요. “아침까지 작업해 주세요”는 조건이 될 수 없어요.
</Q>
<Q q="pstack에 benny라는 자동화 팩이 들어 있다고 들었는데요?">
맞아요. 기본값은 꺼져 있어요. Slack에 제보된 이슈를 분류하고, 버그로 확인된 것들을 고쳐 줘요. 켜려면 Cursor가 benny 폴더 안의 `FOR_AGENTS.md`를 보게 해 주세요.
</Q>
