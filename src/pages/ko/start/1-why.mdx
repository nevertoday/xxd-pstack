## 이런 일, 겪어 봤을 수도 있어요

AI에게 작은 웹페이지나 작은 브라우저 확장 프로그램을 부탁해요. 금방 답이 와요. “다 됐어요!”

열어 보면 버튼을 눌러도 아무 반응이 없어요. “아직 안 돼요”라고 몇 번 말해도 그대로예요.

이유는 간단해요. **“다 됐어요”라고 하기 전에, AI가 직접 열어서 확인해 보지 않았기 때문이에요.**

## pstack을 쓰면 AI가 믿음직한 수리 기사처럼 일해요

물이 새는 수도꼭지를 고치러 사람을 불렀다고 생각해 보세요.

- 믿음직하지 않은 기사는 몇 번 돌려 보고 “고쳤어요” 하고 가 버려요.
- 믿음직한 기사는 먼저 물을 틀어서 정확히 어디서 새는지 봐요. 고친 다음엔 물을 다시 틀어서, 안 새는 걸 당신이 직접 보게 해요. 그제야 일이 끝나요.

pstack은 AI에 설치하는 “믿음직한 기사의 규칙”이에요. 설치하면 AI에게 세 가지 습관이 생겨요.

1. **부탁받은 걸 다시 말해요.** 당신이 원하는 걸 자기 말로 말해요. 잘못 이해했다면 바로 고쳐 줄 수 있어요.
2. **뭔가를 바꾸기 전에, 문제가 어디 있는지 먼저 찾아요.**
3. **끝내기 전에 직접 해 봐요.** 그리고 해 본 결과를 스크린샷 같은 걸로 보여 줘요.

코딩을 모르는 분께 가장 도움이 되는 건 세 번째예요. <mark><strong>코드는 몰라도 돼요. 직접 해 본 결과만 보면 돼요.</strong></mark>

## 준비할 것

- **Claude Code, 그리고 그 안에서 AI와 대화할 수 있을 것.** 아직 설치하지 않았다면 먼저 [Claude Code 공식 빠른 시작 가이드](https://code.claude.com/docs/ko/quickstart)를 따라 설치하고 다시 오세요.
- **Claude 유료 요금제.** Claude Code를 쓰려면 어차피 필요해요.

이게 전부예요. 프로그래밍을 알 필요도, 다른 도구를 먼저 배울 필요도 없어요.

## 조금 느리고, 요금제 사용량을 더 써요

더 많이 확인하고 점검하기 때문이에요. 그러니 작은 일에는 안 써도 돼요.

- **오타 고치기, 색 바꾸기**: AI에게 그냥 말하세요.
- **새로운 걸 만들기, 자꾸 다시 생기는 문제 고치기**: pstack을 쓰세요.
