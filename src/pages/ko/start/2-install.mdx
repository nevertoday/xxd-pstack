평소처럼 Claude Code를 열고, AI와 대화하는 입력창에서 진행해요. 단계는 세 개예요.

<Fig id="l2-install" />

## 1단계: pstack이 어디 있는지 알려 주기

이 한 줄을 복사해서 입력창에 붙여 넣고 Enter를 누르세요.

<Cmd c="/plugin marketplace add cursor/plugins" />

이렇게 하면 Cursor의 “플러그인 스토어”가 추가돼요. pstack은 이 스토어에 있고, Claude Code도 여기서 설치할 수 있어요.

<Callout type="ok">
`Successfully added marketplace: cursor-plugins`라는 문구가 보여요. 스토어를 추가했다는 뜻이에요.
</Callout>

## 2단계: pstack 설치하기

이 한 줄을 복사하고 Enter를 누르세요.

<Cmd c="/plugin install pstack@cursor-plugins" />

화면에 pstack 소개가 나오고, 그 아래에 누구를 위해 설치할지 묻는 선택지 세 개가 나와요.

↑ ↓ 방향키로 첫 번째인 **Install for you**(내 계정에 설치. 어느 폴더에서든 쓸 수 있어요)를 고르고 Enter를 누르세요.

<Callout type="ok">
마지막 줄에 `Plugin is now active.`라고 나와요. 플러그인을 이제 쓸 수 있다는 뜻이에요. 대신 `Run /reload-plugins to apply`(적용하려면 /reload-plugins를 실행하라는 뜻)가 나오면, 그대로 `/reload-plugins`를 입력하고 Enter를 누르세요.
</Callout>

## 3단계: 설치됐는지 확인하기

입력창에 `/pstack:`을 입력하세요. **Enter는 아직 누르지 마세요.**

<Callout type="ok">
`pstack:`으로 시작하는 명령어 목록이 뜨고, 그중에 `/pstack:poteto-mode`가 있어요. 이게 보이면 끝이에요. Esc를 누르면 목록이 닫혀요.
</Callout>

## 이제부터 명령어 앞에 pstack:을 붙여요

설치하고 나면 pstack 명령어는 모두 `pstack:`으로 시작해요. 이 사이트의 다른 페이지에서는 읽기 쉽게 `/poteto-mode`라고 써요. Claude Code에서는 `/pstack:poteto-mode`라고 입력하세요.

따로 설정할 건 없어요. 설치하면 바로 써요.

## 뭔가 이상하다면

<Q q="/plugin을 입력하면 그런 명령어가 없다고 나와요.">

Claude Code 버전이 너무 오래됐어요. 먼저 업데이트하세요.

1. `/exit`를 입력하고 Enter를 눌러 Claude Code를 종료해요.
2. 같은 창에서 `claude update`를 입력하고 Enter를 누른 다음, 끝날 때까지 기다려요.
3. `claude`를 입력하고 Enter를 눌러 다시 열어요. 1단계부터 다시 시작하세요.


</Q>
<Q q="2단계에서 pstack을 찾을 수 없다고 나와요.">
<p>1단계가 제대로 안 됐을 가능성이 커요. 1단계의 줄을 다시 입력하고, `Successfully added marketplace`가 보인 다음에 2단계를 하세요.</p>
</Q>
<Q q="/pstack:을 입력해도 아무것도 안 떠요.">

먼저 다시 열어 보세요. `/exit`로 종료하고, `claude`를 입력한 다음, `/pstack:`을 다시 입력해 보세요.

그래도 안 보이면 `/plugin`을 입력하고 Tab을 눌러 Installed(설치됨) 페이지로 가세요. pstack이 거기 있는지, 켜져 있는지 확인하세요.


</Q>
<Q q="Claude Code가 아니라 Cursor를 써요.">
<p>Cursor 채팅창에 `/add-plugin pstack`을 입력하면 설치돼요. 명령어 앞에 `pstack:`을 붙일 필요도 없어요. 다음 레슨에서 `/pstack:poteto-mode`라고 나오는 곳은 `/poteto-mode`로 입력하세요.</p>
</Q>
