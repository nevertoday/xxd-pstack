Abra o Claude Code do jeito de sempre e use a caixa onde você conversa com a IA. São três passos.

<Fig id="l2-install" />

## Passo 1: diga onde encontrar o pstack

Copie esta linha, cole na caixa e aperte Enter:

<Cmd c="/plugin marketplace add cursor/plugins" />

Isso adiciona a “loja de plugins” do Cursor. O pstack fica nela, e o Claude Code também consegue instalar coisas de lá.

<Callout type="ok">
Aparece `Successfully added marketplace: cursor-plugins` (“loja adicionada com sucesso”).
</Callout>

## Passo 2: instale o pstack

Copie esta linha e aperte Enter:

<Cmd c="/plugin install pstack@cursor-plugins" />

Aparecem na tela as informações do pstack e, embaixo, três opções perguntando para quem é a instalação.

Com as setas ↑ ↓, escolha a primeira, **Install for you** (instalar para você; funciona em qualquer pasta), e aperte Enter.

<Callout type="ok">
A última linha diz `Plugin is now active.` (“o plugin já está ativo”). Se em vez disso disser `Run /reload-plugins to apply` (“rode /reload-plugins para aplicar”), faça o que ele diz: digite `/reload-plugins` e aperte Enter.
</Callout>

## Passo 3: confira se está instalado

Digite `/pstack:` na caixa e **ainda não aperte Enter**.

<Callout type="ok">
Aparece uma lista de comandos que começam com `pstack:`, e um deles é `/pstack:poteto-mode`. Se você vê esse, está pronto. Aperte Esc para fechar a lista.
</Callout>

## De agora em diante, os comandos começam com pstack:

Instalado como plugin, todo comando do pstack fica dentro de `pstack:`. Você digita `/pstack:poteto-mode`; só `/poteto-mode` não é reconhecido. É uma regra do Claude Code para todos os plugins, para que dois plugins não briguem pelo mesmo nome.

Não precisa decorar. Os comandos deste site já aparecem escritos assim, então é só copiar. Não usa o Claude Code? Escolha sua ferramenta aqui e todos os comandos do site mudam para o jeito dela:

<ToolPick />

Não precisa configurar mais nada. Funciona assim que é instalado.

## Se algo der errado

<Q q="Quando digito /plugin, ele diz que o comando não existe.">

Seu Claude Code está desatualizado. Atualize primeiro:

1. Digite `/exit` e aperte Enter para sair do Claude Code.
2. Na mesma janela, digite `claude update`, aperte Enter e espere terminar.
3. Digite `claude` e aperte Enter para abrir de novo. Recomece do passo 1.


</Q>
<Q q="No passo 2, ele diz que não encontra o pstack.">
<p>Provavelmente o passo 1 não deu certo. Digite de novo a linha do passo 1, espere aparecer `Successfully added marketplace` e depois faça o passo 2.</p>
</Q>
<Q q="Não aparece nada quando digito /pstack:.">

Primeiro, abra de novo: digite `/exit` para sair, digite `claude` e tente `/pstack:` outra vez.

Continua sem aparecer? Digite `/plugin` e aperte Tab até chegar na página Installed (instalados). Confira se o pstack está lá e se está ligado.


</Q>
<Q q="Eu uso o Cursor, não o Claude Code.">
<p>Digite `/add-plugin pstack` no chat do Cursor e pronto, está instalado. No Cursor os comandos não levam `pstack:`: escolha Cursor em “Eu uso”, aqui em cima, e os comandos da próxima lição passam a aparecer do jeito do Cursor.</p>
</Q>

## Se você parar de usar

Digite esta linha na caixa e aperte Enter para desinstalar o pstack:

<Cmd c="/plugin uninstall pstack@cursor-plugins" />

Depois digite `/reload-plugins` e aperte Enter (ou abra o Claude Code de novo), e os comandos `/pstack:` somem. Para instalar de novo, recomece do passo dois. Se só quer pausar por um tempo, use `disable` no lugar de `uninstall`, e `enable` para ligar de volta.
