## Отправьте одну команду

<Copy id="setup" code="/setup-pstack" />

Команда проверяет, какие модели вам доступны, и задаёт несколько вопросов. Ваши ответы записываются в файл конфигурации. С этого момента каждый навык берёт модели из него.

## Вопрос о бюджете: не уверены? Выбирайте large

За то, как долго модель может думать, отвечает <Term k="推理预算" />. Чем дольше, тем внимательнее и дороже.

| Вариант | Уровень рассуждений | Для чего подходит |
| --- | --- | --- |
| `large` | `xhigh` (по умолчанию) | Выбирайте, если не уверены |
| `medium` | `high` | Чтобы немного сэкономить |
| `small` | `medium` | Простые задачи, ограниченный бюджет |

`large` — максимальный бюджет. Ни одна роль в pstack не работает выше `xhigh`.

## Вопрос о моделях для ролей: оставьте значения по умолчанию

Каждая <Term k="模型角色" /> может использовать свою модель:

- **Роли для кода, текстов и принятия решений**: по умолчанию opus 5.5.
- **Коллегия ревью**: по умолчанию в неё входят три модели: fable 5.2, opus 5.5 и gemini 4 neon. Они проверяют изменения вместе. Разные модели выбраны намеренно, чтобы находить ошибки друг друга.

Самая дорогая модель, fable 5.2, лишний раз не запускается. Вне коллегии ревью она включается, только если вы укажете её явно или если opus 5.5 дважды не справится с одной и той же задачей.

Меняйте только те роли, которые для вас важны. Значения `auto` или `inherit-parent` означают «использовать ту же модель, что и в основном чате».

<Callout type="tip" title="Если вы пользуетесь Claude Code">
В Claude Code ИИ-помощники могут использовать только модели Claude. Место gemini в коллегии ревью занимает модель вашего текущего чата. Три готовых варианта настройки — в разделе [Использование в Claude Code](/ru/howto/claude-code/#как-лучше-настроить).
</Callout>

## Вопрос о навыке проверки: если вы новичок, отвечайте «да»

Если в вашем проекте пока нет способа доказать, что «приложение действительно работает», команда предложит создать <Term k="验证技能" />.

<strong>Если вы новичок, отвечайте «да».</strong> ИИ, который умеет сам проверять свою работу, продолжает, пока проверка не пройдёт. Вам не придётся проверять всё вручную.

Ещё команда может спросить, нужна ли вам <Term k="形式化验证" /> (это отдельный навык). Отвечайте «да», только если в коде есть сложные для тестирования участки — например, конкурентное выполнение или повторные попытки. Добавить этот навык можно и позже.

## Когда закончите, начните новый чат

Файл конфигурации записывается сюда:

- **Cursor**: `~/.cursor/rules/pstack-models.mdc`
- **Claude Code**: `~/.claude/rules/pstack-models.md`
- **Codex и другие инструменты**: `~/.agents/pstack-models.md`

Cursor и Claude Code читают его только при запуске нового чата. Поэтому <mark>после настройки закройте текущий чат и начните новый</mark>.

## Застряли?

<Q q="Что, если я захочу изменить модели или бюджет позже?">
<p>Запустите <code>/setup-pstack</code> ещё раз. Роли, которые вы изменили, сохранятся. Чтобы вернуть роль к значению по умолчанию, удалите её строку из файла конфигурации.</p>
</Q>
<Q q="В pstack обновились модели по умолчанию, а у меня ничего не изменилось.">
<p>В старом файле конфигурации остались прежние значения. Запустите <code>/setup-pstack</code> ещё раз. Команда заменит те старые значения по умолчанию, которые распознаёт, на новые и покажет, какие именно. Ваши собственные настройки сохранятся. Если какое-то старое значение не распознаётся, сначала удалите эту строку (или весь файл).</p>
</Q>
<Q q="Навык проверки сначала был не нужен, а теперь понадобился.">
<p>Запустите <code>/create-verification-skill</code>. См. <a href="/ru/guide/6-verify-ship/">шаг 6</a>.</p>
</Q>
