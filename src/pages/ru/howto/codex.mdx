## Установка одной командой

Каждый навык pstack — это файл `SKILL.md` в общем формате <Term k="Agent Skill" /> (навык для ИИ-агента), поэтому он устанавливается без Cursor. Введите в терминале:

<Cmd c="npx skills add backnotprop/pstack" />

Нужен Node.js 22.20 или новее. Если не уверены, сначала выполните `node -v`.

Отметьте нужные навыки, затем выберите инструменты для установки. Если не знаете, что отметить, выберите все. Если вам нужны лишь несколько, откройте страницу [Установить только несколько навыков](/ru/howto/pick-skills/).

<Callout type="tip" title="Установка для всех проектов">
<p>По умолчанию pstack устанавливается только в папку текущего проекта. Чтобы он был доступен во всех проектах, добавьте <code>-g</code>:</p>
<p><Cmd c="npx skills add backnotprop/pstack -g" /></p>
</Callout>

## Проверьте, куда установились навыки

Ищите подпапки вроде `poteto-mode` в соответствующей папке:

| Инструмент | Этот проект | Все проекты (-g) |
| --- | --- | --- |
| Codex и другие | `.agents/skills/` | `~/.agents/skills/` |
| Claude Code | `.claude/skills/` | `~/.claude/skills/` |
| Pi | `.pi/skills/` | `~/.pi/agent/skills/` |
| Cursor | `.cursor/skills/` | `~/.cursor/skills/` |

Codex также читает `~/.codex/skills/`.

<mark>Навыки не запускаются сами по себе</mark>. Кроме `setup-pstack`, каждый из них срабатывает только тогда, когда вы его назовёте.

## Выберите модели

После установки один раз запустите `setup-pstack`. Он выводит список доступных вам моделей, спрашивает про ваш <Term k="推理预算" /> (как долго моделям думать), а затем записывает один файл:

<Copy id="codex-file" title="Где лежит файл настроек" code="~/.agents/pstack-models.md" />

Навыки сами читают его при выборе модели, так что начинать новый чат не нужно.

<Callout type="warn" title="Запустите настройку хотя бы один раз">
Названия моделей по умолчанию в pstack указаны для Cursor. Если в вашем инструменте такого названия нет, навык переключается на ближайшую модель. Если ничего близкого нет, он использует модель текущего чата и сообщает об этом. Запустите настройку один раз — и каждая роль получит модель, которая у вас действительно есть.
</Callout>

## Ваша первая задача

В Codex навык вызывают через `$` и его название, например `$poteto-mode`. По умолчанию команды на этом сайте написаны для Claude Code (`/pstack:poteto-mode`). Выберите здесь Codex — и все команды на сайте переключатся на формат с `$`:

<ToolPick />

Отправьте первую задачу так:

<Copy id="codex-first" title="В Codex вызывайте навык через $" code="$poteto-mode добавь флаг --json к этой команде. Текущий текстовый вывод должен остаться идентичным байт в байт. Проверь оба варианта вывода." />

Можно также написать «используй для этого навык poteto-mode». В других инструментах используйте их собственный синтаксис. Как лучше сформулировать это сообщение, читайте в разделе [Ваша первая задача](/ru/guide/3-first-task/).

## Если в вашем инструменте чего-то нет, ИИ подстроится

В навыках используются названия из Cursor, а ИИ сам их адаптирует. Вот что вы заметите:

- **Нельзя запускать ИИ-помощников** (<Term k="子代理" text="субагентов" />): шаги, которые должны выполняться параллельно, идут по очереди — чуть медленнее.
- **Нет инструмента для вопросов**: ИИ выводит в чате пронумерованный список вариантов.
- **Нет `/loop`**: ИИ использует команду ожидания по таймеру и проверяет снова позже.
- **Нет Custom Mode** (пользовательского режима, который остаётся включённым на каждом сообщении): он есть только в Cursor. Пишите `poteto-mode` в начале каждой новой задачи.

`deslop`, `control-cli` и `control-ui` относятся к другому плагину для Cursor. Без них ИИ использует те инструменты, которые у вас есть, например Playwright или tmux.

## Застряли?

<Q q="npx skills выдаёт ошибку и не запускается.">
Сначала выполните `node -v`. Если версия ниже 22.20, обновите Node.js и попробуйте снова.
</Q>
<Q q="Не могу найти навыки pstack в другом проекте.">
<u>По умолчанию pstack устанавливается только в тот проект, в котором вы находились</u>. Запустите установку ещё раз в новом проекте или добавьте `-g`, чтобы установить для всех проектов.
</Q>
<Q q="После изменения настроек моделей они, похоже, не применяются.">
Откройте `~/.agents/pstack-models.md` и проверьте, что в строке указана выбранная вами модель. Затем убедитесь, что такое название есть в вашем инструменте. Если его нет, навык переключается на ближайшую модель и сообщает об этом в ответе.
</Q>
