## Установка одной командой

В поле чата Cursor введите:

<Cmd c="/add-plugin pstack" />

Установка через Customize на боковой панели работает точно так же. Затем выберите модели:

<Cmd c="/setup-pstack" />

Команда спросит про ваш <Term k="推理预算" /> (как долго модели думают), назначит модель на каждую <Term k="模型角色" /> и запишет настройки в `~/.cursor/rules/pstack-models.mdc`.

<Callout type="tip" title="После настройки начните новый чат">
<u>Эти настройки действуют только для новых чатов</u>. Если продолжите в старом, он по-прежнему будет использовать модели по умолчанию.
</Callout>

По умолчанию команды на этом сайте записаны для плагина Claude Code — с префиксом `pstack:`, который Cursor не использует. Выберите здесь Cursor, и все команды на сайте переключатся на формат Cursor — останется только скопировать:

<ToolPick />

## Выберите /poteto-mode из меню /

Введите `/` в поле чата, выберите `/poteto-mode` в меню и опишите задачу:

<Copy id="cursor-first" title="Ваша первая задача" code="/poteto-mode добавь флаг --json к этой команде. Текущий текстовый вывод должен остаться идентичным байт в байт. Проверь оба варианта вывода." />

Есть разница, какой клавишей отправить сообщение:

- **Enter**: действует только на это одно сообщение. Через несколько сообщений перестаёт работать.
- **Option+Enter (Mac) или Alt+Enter (Windows)**: <mark>переходит в <Term k="Custom Mode" /> (пользовательский режим в Cursor) и остаётся включённым на каждом сообщении</mark>, пока вы не выйдете из режима.

Когда Custom Mode включён, в следующих сообщениях достаточно написать «делай» или «продолжай».

Когда закончите одну задачу и перейдёте к следующей, начните с «new task». Иначе ИИ воспримет ваш новый вопрос как следующий шаг предыдущей задачи.

## Передайте задачу перед сном: /loop

`/loop` — встроенная команда Cursor. Она время от времени будит ИИ, чтобы проверить, завершена ли работа. Задайте условие готовности, которое либо выполняется, либо нет:

<Copy id="cursor-loop" title="Перед сном" code={`/poteto-mode Я иду спать. В новом worktree (от ветки <ваша базовая ветка>) переведи все вызовы на новый парсер.
Готово — значит: старых вызовов не осталось, все фикстуры парсера проходят, а старый API удалён.
Веди журнал решений. Перед коммитами спрашивать меня не нужно.
/loop until done. Если через несколько часов действительно застрянешь, остановись и запиши почему.`} />

«Поработай 4 часа» — это не условие готовности. Проверять тут нечего, так что утром вас ждут 4 часа пустой возни. Подробный вариант — в разделе [Оставить работать самостоятельно](/ru/guide/7-overnight/).

## Несколько ИИ одновременно: выделите каждому своё пространство

Если несколько ИИ меняют код в одной папке, они перезаписывают правки друг друга. Два способа развести их:

- **В облаке**: введите `/in-cloud` перед задачей. Каждый ИИ получит свою машину и ветку, а ваш компьютер останется нетронутым.
- **Локально**: выделите каждой задаче свой <Term k="worktree" /> (отдельная рабочая папка того же Git-репозитория). На ноутбуке достаточно нескольких одновременно.

<Copy id="cursor-wt" code={`/poteto-mode new task. Создай новый worktree от <базовая ветка> и перенеси туда изменения парсера.`} />

## Что стоит установить отдельно

Несколько шагов `/poteto-mode` используют плагин `cursor-team-kit`. Без него всё тоже работает, но эти шаги справляются слабее. Чтобы получить полный набор, установите плагин. В него входят:

- **`deslop`**: убирает из кода «ИИ-почерк».
- **`control-cli`**: управляет программами командной строки.
- **`control-ui`**: управляет браузерами и веб-страницами.

В pstack нет навыка планирования. Используйте вместе с ним встроенный в Cursor режим Plan Mode.

## Застряли?

<Q q="/poteto-mode перестаёт работать через несколько сообщений.">
Скорее всего, вы отправили его по Enter. Выберите команду из меню ещё раз и нажмите Option+Enter (Alt+Enter на Windows). Или вводите `/poteto-mode` заново для каждой новой задачи.
</Q>
<Q q="Меняю настройки моделей, но всё равно запускаются старые.">
Настройки действуют только для новых чатов. Начните новый и попробуйте снова.
</Q>
<Q q="Несколько ИИ работали одновременно и перемешали мои файлы.">
Выделите каждой задаче свой worktree или отправьте её в облако командой `/in-cloud`.
</Q>
<Q q="/loop работал всю ночь, но ничего не доделал.">
Условие готовности должно либо выполняться, либо нет — например, «эта команда возвращает 0» или «все эти тесты проходят». Вариант «работай до утра» не считается.
</Q>
<Q q="Говорят, в pstack есть набор автоматизации под названием benny?">
Да, но по умолчанию он отключён. Он разбирает сообщения о проблемах из Slack и исправляет те, которые подтвердились как баги. Чтобы его включить, дайте Cursor файл `FOR_AGENTS.md` из папки benny.
</Q>
