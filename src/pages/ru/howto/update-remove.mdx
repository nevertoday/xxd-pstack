## Команды по способу установки

Выберите вкладку по команде, которую вы вводили при установке:

- `npx skills add` → командная строка skills
- `/plugin install` → плагин Claude Code
- `/add-plugin` → плагин Cursor

Не помните? Если для команд нужен префикс `pstack:`, значит, у вас плагин Claude Code.

<Tabs id="ur" items={[["skills","Командная строка skills"],["cc","Плагин Claude Code"],["cursor","Плагин Cursor"]]}>
<div slot="skills">
<p>Выполняйте эти команды в терминале (не в чате с ИИ):</p>
<p><Cmd c="npx skills list" /> Посмотреть, какие навыки установлены.</p>
<p><Cmd c="npx skills check" /> Проверить наличие новых версий.</p>
<p><Cmd c="npx skills update" /> Обновить до последней версии.</p>
<p><Cmd c="npx skills remove" /> Удалить навыки.</p>
<p>Навыки, установленные без <code>-g</code>, хранятся только в том проекте, в котором вы тогда находились.</p>
</div>
<div slot="cc">
<p>Сторонние плагины по умолчанию не обновляются сами. Чтобы обновить вручную один раз (выполните в терминале):</p>
<p><Cmd c="claude plugin update pstack@cursor-plugins" /></p>
<p>Чтобы включить автообновление: введите <code>/plugin</code>, откройте вкладку <strong>marketplaces</strong>, выберите <code>cursor-plugins</code>, а затем — <strong>enable auto-update</strong>.</p>
<p>Вводите эти команды в чате Claude Code:</p>
<p><Cmd c="/plugin list" /> Посмотреть, какие плагины установлены и включены ли они.</p>
<p><Cmd c="/plugin uninstall pstack@cursor-plugins" /> Удалить.</p>
<p><Cmd c="/plugin disable pstack@cursor-plugins" /> Временно отключить. Вернуть обратно позже можно командой <code>/plugin enable pstack@cursor-plugins</code>.</p>
<p>После удаления или отключения введите <code>/reload-plugins</code> или перезапустите Claude Code. Чтобы убрать и магазин плагинов, который вы добавляли при установке: <code>/plugin marketplace remove cursor-plugins</code>. Учтите, что вместе с ним удалятся все остальные плагины, установленные из этого магазина.</p>
</div>

</div>

## После обновления: запустите настройку заново

`/setup-pstack` записывает в файл настроек пары «<Term k="模型角色" /> — модель», по одной на строку. Если новая версия меняет модели по умолчанию, в вашем файле всё ещё указаны прежние. <mark>Когда навык читает эту строку, он продолжает использовать старую модель</mark>.

<Cmd c="/setup-pstack" />

Команда распознаёт старые значения по умолчанию, заменяет их на новые и сообщает, какие именно. Модели, которые вы выбрали сами, останутся без изменений. Если файл создан старой версией, `/poteto-mode` напомнит об этом один раз в каждом чате.

Если в файле есть старое значение, которое команда не распознаёт, сначала откройте файл настроек и удалите эту строку (или весь файл), а затем запустите команду снова.

| Инструмент | Файл настроек |
| --- | --- |
| Cursor | `~/.cursor/rules/pstack-models.mdc` |
| Claude Code | `~/.claude/rules/pstack-models.md` |
| Codex и другие | `~/.agents/pstack-models.md` |

<Callout type="ok" title="Повторный запуск безопасен">
При повторном запуске `/setup-pstack` роли, которые вы изменили сами, сохраняются. После этого начните новый чат, иначе изменения не применятся.
</Callout>

## После удаления: удалите и файл настроек

Удаление pstack не затрагивает файл настроек. Claude Code подгружает его в каждую новую сессию, так что он просто занимает место в контексте. Если pstack вам больше не нужен, удалите заодно этот файл из таблицы выше.

Сгенерированный <Term k="验证技能" /> (папка вроде `verify-your-app`) относится к вашему проекту и не удаляется вместе с pstack.

## Застряли?

<Q q="После обновления всё равно используются старые модели.">
Скорее всего, дело в старом файле настроек. Запустите `/setup-pstack` ещё раз. Если это не поможет, удалите строку с этой ролью. Затем начните новый чат.
</Q>
<Q q="В npx skills list не видно навыков pstack.">
Убедитесь, что вы запускаете команду в папке того проекта, куда устанавливали pstack. Навыки, установленные в проект, и навыки, установленные с `-g`, хранятся в разных местах.
</Q>
