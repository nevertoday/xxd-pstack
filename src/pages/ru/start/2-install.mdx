Откройте Claude Code, как обычно. Всё делается в поле, где вы переписываетесь с ИИ. Шагов три.

## Шаг 1. Подскажите, где искать pstack

Скопируйте эту строку, вставьте в поле и нажмите Enter:

<Cmd c="/plugin marketplace add cursor/plugins" />

Так вы подключаете «магазин плагинов» Cursor. pstack лежит там, и Claude Code тоже умеет оттуда устанавливать.

<Callout type="ok">
Появляется `Successfully added marketplace: cursor-plugins` («магазин успешно добавлен»).
</Callout>

## Шаг 2. Установите pstack

Скопируйте эту строку и нажмите Enter:

<Cmd c="/plugin install pstack@cursor-plugins" />

На экране откроется описание pstack, а под ним три варианта: для кого устанавливать.

Стрелками ↑ ↓ выберите первый, **Install for you** («установить для себя», работает в любой папке), и нажмите Enter.

<Callout type="ok">
В последней строке написано `Plugin is now active.` («плагин уже работает»). Если там написано `Run /reload-plugins to apply` («чтобы применить, выполните /reload-plugins»), сделайте, как сказано: введите `/reload-plugins` и нажмите Enter.
</Callout>

## Шаг 3. Проверьте, что всё установилось

Наберите в поле `/pstack:` и **пока не нажимайте Enter**.

<Callout type="ok">
Всплывает список команд, которые начинаются с `pstack:`, и среди них есть `/pstack:poteto-mode`. Видите её — значит, готово. Нажмите Esc, чтобы закрыть список.
</Callout>

## Теперь команды начинаются с pstack:

После установки все команды pstack начинаются с `pstack:`. На других страницах сайта для простоты пишут `/poteto-mode`. А в Claude Code вы набираете `/pstack:poteto-mode`.

Больше ничего настраивать не нужно. Он работает сразу после установки.

## Если что-то пошло не так

<Q q="Когда я ввожу /plugin, пишет, что такой команды нет.">

У вас слишком старая версия Claude Code. Сначала обновите её:

1. Введите `/exit` и нажмите Enter, чтобы выйти из Claude Code.
2. В том же окне введите `claude update`, нажмите Enter и дождитесь, пока обновление закончится.
3. Введите `claude` и нажмите Enter, чтобы снова его открыть. Начните заново с шага 1.


</Q>
<Q q="На шаге 2 пишет, что pstack не найден.">
<p>Скорее всего, шаг 1 не сработал. Введите строку из шага 1 ещё раз, дождитесь `Successfully added marketplace`, а потом сделайте шаг 2.</p>
</Q>
<Q q="Когда я набираю /pstack:, ничего не всплывает.">

Сначала перезапустите его: введите `/exit`, чтобы выйти, потом `claude`, и снова наберите `/pstack:`.

Всё равно нет? Введите `/plugin` и нажимайте Tab, пока не откроется вкладка Installed («установленные»). Проверьте, что pstack там есть и включён.


</Q>
<Q q="У меня Cursor, а не Claude Code.">
<p>Введите `/add-plugin pstack` в поле чата Cursor, и он установится. Приставка `pstack:` в командах тоже не нужна. Там, где в следующем уроке написано `/pstack:poteto-mode`, набирайте `/poteto-mode`.</p>
</Q>
