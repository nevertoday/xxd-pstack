## 你可能遇到过这种事

你让 AI 做一个小网页，或者一个小插件。它很快回你：「做好了！」

你一打开，按钮点了没反应。你回去说「还是不行」，它说「抱歉，已经修复」。你再打开，还是一样。来回几次，你开始怀疑是不是自己哪里没说清楚。

这不怪你。**AI 说「好了」的时候，它自己并没有打开看过。**

## pstack 让它像个靠谱的师傅

打个比方。你请师傅修漏水的水龙头：

- 不靠谱的师傅拧两下，说「好了」，走了。
- 靠谱的师傅先打开水龙头，看清楚哪里在漏；修完再打开一次，让你亲眼看着不漏了，才收工。

pstack 就是一份装进 AI 里的「靠谱师傅守则」。装上以后，AI 做事会多三个习惯：

1. **先复述。** 它先用自己的话说一遍你要什么。理解错了，你马上就能纠正。
2. **先弄清楚问题在哪，再动手改。**
3. **做完拿出证据。** 比如截图，或者它亲手试过一遍的结果。

第三条对不会写代码的人最有用：<mark><strong>你不需要看懂代码，只需要看懂证据。</strong></mark>

## 你要准备什么

- **Claude Code，并且已经能在里面和 AI 聊天。** 还没装的话，先照 [Claude Code 官方上手指南](https://code.claude.com/docs/zh-CN/quickstart) 装好，再回来。
- **Claude 的付费订阅。** 用 Claude Code 本来就需要。

就这些。不需要会编程，也不需要先学别的工具。

## 它会慢一点，多用一点额度

因为它要多检查、多确认。所以小事不用它：

- **改个错别字、换个颜色**：直接跟 AI 说就行。
- **做个新东西、修一个老是出现的问题**：用 pstack。
