这一课用 pstack 做一个真的小东西：一个记录每天喝了几杯水的网页。做完你就知道它和平常的 AI 有什么不一样。

## 先准备一个空文件夹

1. 在桌面新建一个文件夹，名字叫 `water`。
2. 如果 Claude Code 开着，先输入 `/exit` 退出。
3. 在同一个窗口里输入下面这行，回车。意思是「走进桌面上的 water 文件夹」：

<Cmd c="cd ~/Desktop/water" />

4. 再输入 `claude`，回车，Claude Code 就在这个文件夹里打开了。

为什么要新建文件夹：你在哪个文件夹里打开 Claude Code，AI 就在哪里干活。新的空文件夹里，它碰不到你电脑上别的东西。

## 把这段话发给它

<Copy id="first" title="复制，粘贴进输入框，回车" code={`/pstack:poteto-mode 帮我做一个记录每天喝水的小网页。这是一个空文件夹，需要的准备工作你来做。
做好的样子：我打开网页，点一下「喝了一杯」，今天的杯数加一；关掉再打开，数字还在；页面上能看到最近 7 天每天喝了几杯。
做完给我看：你是怎么检查的，做了哪些操作，看到了什么结果，能截图就截一张。最后告诉我怎么打开这个网页。`} />

开头的 `/pstack:poteto-mode` 是开关。打了它，AI 才按 pstack 的规矩做事；不打，它就还是平常那样。

后面的话只有三部分，这就是用 pstack 的全部窍门：

<mark><strong>我想要什么 · 做好是什么样子 · 做完给我看什么</strong></mark>

- **我想要什么**：一个记录喝水的网页。
- **做好是什么样子**：点了会加一，关掉再开还在，能看到 7 天。这是在告诉它「怎么算做完」，它会照着这几条去检查。
- **做完给我看什么**：它检查的过程和结果。你看不懂代码，所以要它拿出你看得懂的东西。

## 它会停下来问你

它会干上几分钟。中途 Claude Code 会停下来问你：可以新建这个文件吗？可以运行这个命令吗？

这是 Claude Code 在保护你：每一步都要你点头。这个文件夹是新建的、空的，选 **Yes** 就行。

## 它的回复先看哪里

它的回复会比平常长，可能夹着英文和专业词。看不懂的部分直接跳过，**只看下面标出来的四处**：

<Reply code={`① 我理解的目标：一个记录喝水的网页。点「喝了一杯」，今天的杯数加一；
   关掉再打开，数字还在；能看到最近 7 天每天喝了几杯。

② 待办
   ☐ 准备好这个文件夹
   ☐ 做网页
   ☐ 检查：加一杯、关掉重开、看 7 天
   ☐ 把检查结果交给你

   ……（中间是它干活的过程，可以不看）……

③ 检查结果
   ✓ 点了 3 次「喝了一杯」，今天显示 3 杯
   ✓ 关掉页面再打开，还是 3 杯
   ✓ 最近 7 天每天都有一根柱子，今天这根最高
   ? 没法确定：手机上的样子，我只在电脑上检查了

④ 怎么打开：双击 water 文件夹里的 index.html`} />

- **①先看这里。** 它理解得对不对？不对就直接打字纠正，比如「不是 7 天，是 30 天」。
- **②是它打算做的步骤。** 做的过程中会一项项打勾，你不用管。
- **③最重要。** 每一条都写着它做了什么、看到了什么。写着「没法确定」的那条，是它在说实话，这是好事。
- **④照着做，自己打开看一眼。**

## 怎么判断它做得好不好

问自己三个问题：

- 它复述的目标，和我想的一样吗？
- 它说做完的时候，列出了实际做过的检查和结果吗？
- 我自己打开看，和它说的一样吗？

三个都是「是」，这件事就做好了。

如果它只说了一句「已完成」，没有任何检查结果，那就是没做完。回它：

<Copy id="no-proof" code="给我看你实际检查的结果：做了哪些操作，看到了什么。不要只说做完了。" />

## 不对的时候怎么说

<Q q="做出来不对，比如点了按钮数字没变。">
<p>只说你看到的，比如：「我点了三次，数字一直是 0。」不用猜原因，猜错了会把它带偏。</p>
</Q>
<Q q="回复太长，全是看不懂的词。">
<p>输入 `/pstack:bro`，它会把上一条回复用大白话重说一遍，短很多。</p>
</Q>
<Q q="它问了我一个看不懂的问题。">
<p>直接回它：「我不会编程，请用大白话问我；或者你替我选一个最稳妥的，并告诉我为什么。」</p>
</Q>
<Q q="它在做我没让它做的事，我想让它停下。">
<p>按 Esc，它就停了。然后告诉它你想要什么，比如「只做喝水记录，别的先不加」。</p>
</Q>
<Q q="Windows 上 cd 那一行提示找不到文件夹。">
<p>有的 Windows 电脑，桌面在 OneDrive 里。改成输入 `cd ~/OneDrive/Desktop/water` 试试。</p>
</Q>
<Q q="我用的是桌面版 Claude，没有输入 cd 的地方。">
<p>新开一个会话时，它会让你选一个文件夹。选桌面上的 water，后面的步骤都一样。</p>
</Q>

## 你已经会了

以后做任何事，都是同一个样子：`/pstack:poteto-mode`，加上三部分。再看两个例子：

<Copy id="ex-fix" title="修一个老是出现的问题" code={`/pstack:poteto-mode 我的收藏插件，点收藏有时会出现两条一样的。
做好的样子：连着点十次收藏，列表里也只有一条。
做完给我看：你是怎么让这个问题重新出现的，修好以后再试一次的结果。`} />

<Copy id="ex-how" title="不改东西，只想弄懂" code="/pstack:how 这个文件夹里的东西是怎么工作的？用大白话讲，我不会编程。" />

第二个例子用的是 `/pstack:how`：只讲解，不动你的东西。想先弄明白再决定改不改的时候，用它。
